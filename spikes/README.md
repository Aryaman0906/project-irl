# Technical Spike Policy and Backlog

Spike code is experimental and never becomes production code silently. No result is fact until the experiment is run and recorded. Every spike directory must contain a `README.md` covering: question, assumptions, experiment, result, limitations, recommendation, and production implications.

Backlog: `SPIKE-ANDROID-USAGE`, `SPIKE-IOS-DEVICE-ACTIVITY`, `SPIKE-PERMISSION-LOSS`, `SPIKE-OFFLINE-RESUME`, and `SPIKE-SYNC-IDEMPOTENCY`. Prioritize only after Phase-0 review.
